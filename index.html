Facebook Pages

Login karo, apna Page select karo — bas. Ek se zyada Pages bhi connect ho sakte hain; post Active Page pe jati hai.

Abhi koi Facebook account connected nahi hai. Upar wala button daba ke login karo — phir apna Page select kar lena.

Instagram Accounts

Instagram alag se login nahi hota — jo IG account tumhare Page se linked hoga, woh Facebook login pe khud aa jaye ga.

Abhi koi Instagram account detect nahi hua.

Instagram connect karne ke liye: Instagram app mein apna account Business ya Creator banao (Settings → Account type), phir usay apne Facebook Page se link karo (Page Settings → Linked accounts → Instagram) — aur yahan Facebook se dobara login karo, account khud aa jaye ga.

App Install Karo

Is app ko apne Android phone pe install kar sakte ho — phir ye home screen se ek asli app ki tarah khule gi.

  1. Chrome ke menu (⋮) pe tap karo
  2. “Install app” ya “Add to Home screen” select karo
  3. Confirm kar do — icon home screen pe aa jaye ga
