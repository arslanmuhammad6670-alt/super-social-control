WhatsApp OTP

Login screen pe WhatsApp OTP chalane ke liye apni Meta WhatsApp Business API ki details yahan dalo. Ye Meta for Developers → WhatsApp → API Setup se milti hain. Template message mein ek body parameter {{1}} hona chahiye — code usi mein jata hai (“Tumhara Super Social Control code hai: {{1}}”). Dono fields bhar jayen to login screen ka WhatsApp button khud active ho jaye ga.

Tumhara default token pehle se laga hua hai — kuch karne ki zaroorat nahi. Token expire ho jaye to naya token yahan dal do, wohi use hoga.

Meta mein jo OTP template banaya ho, usi ka naam yahan likho. Khali chhor do to super_social_otp use hoga (language: en_US).
